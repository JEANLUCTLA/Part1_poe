# Part One POE – Registration and Login System

## Overview

This project is a Java-based registration and login system created for Part One of my POE. The program allows users to register their details and then log in using their registered information.

## Features

* Captures the user's **first name and last name**.
* Captures a **username**.
* Captures a **phone number with an international country code**, such as **+27** for South Africa.
* Validates the information entered by the user.
* Displays **error messages** when information is entered incorrectly.
* Displays **welcome and success messages** when registration and login are completed correctly.
* Provides a simple and user-friendly registration and login process.
